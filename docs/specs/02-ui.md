# 02 — User interface

**Status:** DRAFT v2 — proposal awaiting validation

## Style
- A **semi-transparent dark table** (about 75% opacity), using the game's font and colors so it
  doesn't look out of place.
- **Foldable sections:** collapsed, the panel only shows the main figure per player. Clicking a
  section header (▸/▾) unfolds its detail. Fold states are remembered.
- Each player row has a colored bar showing their share of the total (WoW-meter style), using the
  character color.
- Languages: **English and French**, following the game's language setting by default (can be
  forced in the settings).

## 1. Live overlay (during combat)

Collapsed (default):
```
┌ KikiMAIster ─────────── [Turn|Combat|Run] ─ ✕ ┐
│ ▸ Damage                                      │
│   Ironclad  Kiki  ████████████░░  142  (58%)  │
│   Silent    Max   ████████░░░░░░  103  (42%)  │
│ ▸ Protection                                  │
│ ▸ Debuffs                                     │
│ ▸ Taken                                       │
│ ▸ Friendly fire                               │
└───────────────────────────────────────────────┘
```

With the "Protection" section unfolded:
```
│ ▾ Protection          Prevented  Allies  Wasted/Useless │
│   Kiki                    38        12        7 / 5      │
│   Max                     21         0        9 / 0      │
```

- Only the most important section is unfolded by default (Damage).
- Hovering a figure shows its detail (e.g. damage by source, debuffs by type).
- **Scope switch:** Turn / Combat / Run.
- **Hotkey** `F7` shows/hides the panel; the panel can be dragged and its position is remembered.
- Overlay size: compact by default; a settings option scales it from 75% to 150%.

## 2. End-of-combat summary
- **v0.6.0 (built):** a window opens at the top center of the screen when a combat ends: "Combat N · Victory/Defeat · R rounds".
  It holds a **cumulative chart by round**, one line per player in their character color, and a selector for the stat shown:
  Damage / Prevented / HP lost / Debuff stacks. Hovering a dot shows its value; the legend shows each player's final total.
  ✕ closes it. Not yet built: MVP line, auto-show setting.
- **v0.6.1:** a selector at the top picks the combat: "▶ Combat N · <encounter> · in progress (round R)", updated live,
  then every finished combat of the run, newest first ("Combat N · <encounter> · Victory · R rounds"). The overlay's
  "Summary" button opens it on the combat in progress, else on the last finished one. The list restarts with each run
  and is not kept across Save & Quit.
- Appears on the rewards screen in the same table style, with every section unfolded.
- An **MVP** line on top: top damage, top protector, top debuffer, most useless help 😄.
- Close button, plus a setting to turn auto-display off.

## 3. End-of-run summary
- Appears on the game's end-of-run screen (victory or defeat).
- Tabs: **Totals** (same sections as the overlay), **Per act**, **Records** (biggest hit, best
  combat, most damage prevented in one combat…).
- Saved automatically as a JSON file in the mod folder (`runs/`), for later comparison.

## 4. Settings
Built in v0.9.0: language (auto / EN / FR), auto-show summaries, shown sections and columns.
Not yet: hotkey, overlay opacity and scale.

## Changes after Zaille75's first test (v0.2.2)
- **Row details:** hover over a player's row to see its details as a tooltip. Click the row to open the details inside the panel, and click again to close them.
- **Language:** an EN/FR button in the header switches the mod's language. "auto", the default, follows the game language.
- **Names:** card, power, relic and potion names come from the game's own translations, so they appear in the game's language.

## Changes after the second test (v0.3.0)
- **Damage section:** the bar is gone. The section now shows Total (with the player's share), then one column per kind of damage: Cards, each damage-over-time debuff by its game name (Poison, Doom…), Powers, Pet, Orbs, Relics, Potions, Other. Only kinds that dealt damage in the current scope are shown.
- **Player names:** in co-op the mod shows the player's Steam name. In solo it shows the character name.
- **Run totals survive Save & Quit:** after each combat, the run totals are written to `runs/P<profile>_<seed>_A<ascension>_<players>.txt` (profile, seed and player ids keep solo, co-op and other profiles apart) next to the DLL. When a run is continued, they are restored. A file saved on a later floor than the current one means a new run on the same seed, so it is ignored. The 30 most recent files are kept.
- **Solo layout (v0.3.5, replaces v0.3.3):** in solo every section always shows its table, without the player-name column. The section title is on the same line as the column names (v0.3.6), with the values on the line below. Opening a section (click its title or a value) adds its details below the table, the same content as the tooltip.
- **v0.4.0:** Protection shows Évités | Pour alliés | Gâché | Inutile (rule F3 in 01-metrics). Affaiblissements shows one column per debuff applied, as "x/y" (times applied / stacks). In solo, every ally column and ally tooltip line is hidden, and the damage total has no "%".
- **v0.4.1:** every section starts folded each time the game starts (open sections are no longer saved). The panel shrinks back to its content when sections are folded.
- **v0.4.3:** the panel stays on screen. When it grows past the right or bottom edge, it is shown further left or up. It goes back to the position the player chose once it shrinks.
- **v0.5.0:** the "Évités" total also includes HP loss reduced by relics/powers (Tungsten Rod…). The details list each source.
- **v0.6.2:** a summary that opened by itself at the end of a combat closes when the map opens (rewards done) or when the next combat starts. A summary opened with the "Summary" button stays until it is closed. A checkbox in the window, "Show at the end of each combat" (saved, on by default), turns the automatic opening on or off.
- **v0.7.0:** the "Turn" tab is replaced by **"Last turn"** ("Tour préc."): the last finished round (your turn plus the enemies' answer), including its wasted block, which is only known when the next round starts. At the end of a combat, it shows the final round.
  - **Why wasted:** hovering the Protection values (or opening the details) lists the reason for each wasted block, most recent first, at most 5: "Round 3 · Defend: 5 wasted. In hand: Strike, Neutralize · block 12 · incoming attack 7 → Strike could have been played instead."
  - "In hand" lists only the useful cards left unplayed at the end of the turn. "Block" is the player's block when the turn ended. "Incoming attack" is the attack damage the enemies announced against that player. These reasons are not kept across Save & Quit.
- **v0.7.1:** the summary window can be dragged by any empty area (also the chart), and its position is saved. It is kept on screen. Before it is first moved, it opens at the top center.
- **v0.8.0:** the "Cartes" damage column is renamed **"Direct"** (damage of the card played itself).
- **v0.9.0 (after the first co-op games):**
  - **Sections:** Dégâts · Protection · Affaiblissements · **Occasions manquées** · Subis · **Coop** (co-op only) · **Autres**.
    "Tirs amis" is gone: damage dealt to allies is in Coop, damage received from allies in Subis ("Par alliés").
    - Protection: Évités | Armure | Familier | Inutile | PV familier. "Armure" = damage stopped by block, "Familier" = damage
      the pet took. Gâché and inutile are one "Inutile" column; the gâché part moves to Occasions manquées.
    - Affaiblissements: one column per debuff, plus "Effet" (extra damage from Vulnerable + damage avoided by Weak / Strength −).
    - Occasions manquées: Létal (missed lethal turns) | Gâché (wasted block) | Petite att. (weak attacks). The details list the
      latest of each: "T3 · létal manqué : Frappe + Frappe lourde (ennemis 18 PV)", "T3 · attaque 7 → armure 12 → Défense
      (5 gâchés) → Frappe" (incoming attack → block already there → card played → what could have been played),
      "T2 · Frappe (6) au lieu de Frappe lourde (14)".
    - Coop: Armure donnée | PV sauvés | Permis | Tirs amis | Morts.
    - Autres: Piochées | Jouées | Épuisées | Défaussées | Potions.
  - **Co-op layout:** an open section puts its title on the column-name line (one line less). Players are listed **from the
    best to the worst** for that section (most damage, most prevented…; fewest HP lost / missed chances). A clicked player's
    details open **right under their line**, without repeating the name.
  - **Colors:** two players with the same character get the same color shades as in the chart (the second one lighter).
  - **Shorter tooltips:** one line of key figures, zero values left out, then the breakdown.
  - **Settings (⚙ button, replaces the EN/FR button):** language (game / English / Français), automatic summary, and a
    checkbox for every section and every column (saved).
  - **Previous fights:** in the Combat tab, "◂ Combat N · name · result ▸" browses the combats of the run (the latest
    one, live while in progress, comes first). Not kept across Save & Quit.
  - **Summary window:** moves out of the panel's way when they overlap (the panel grows when sections open). The
    "Évités" chart is removed; "PV sauvés" is added in co-op. A **Cumulé / Par tour** button switches between running
    totals and the values of each round (saved). In co-op, a **Coop summary** of the combat sits next to the chart.
  - **End-of-run window (Trophées):** opens when the run ends (victory or defeat), and from the "Trophées" button of the
    summary window at any time. One line per trophy: winner, value, **all-time record** (value, player, date) and the
    winner's **personal best**; ★ marks a new record. Records are saved in `KikiMAIster.records.cfg` next to the DLL and
    only change when a run ends. Proposed trophies (to discuss): Gros bras (damage), Coup de massue (biggest hit), Bourreau
    (kills), Maître des malus (debuff stacks), Forteresse (prevented), Ange gardien (HP saved for allies), Catalyseur
    (damage enabled for allies), Intouchable (fewest HP lost, victories only); for fun: Maçon du dimanche (useless block),
    Distrait (missed chances), Traître (friendly fire), Kamikaze (deaths).
- **v0.9.1:** audit of every block card for side effects (spec 01-metrics F4): Hologram, Cosmic Indifference, Compact, Constellation, Bulwark, Hand Trick and Genetic Algorithm are never gâché.
- **v0.10.0:** Occasions manquées columns: Létal | Gâché | Choix (weak attack, smaller block, Pen Nib, Orichalcum, Genetic
  Algorithm / The Scythe not played) | Énergie | Évitables (HP) | Reliques | Potions. The details list the latest of each.
