# 02 — User interface

**Status:** DRAFT — awaiting validation by Zaille75

## 1. Live overlay (during combat)
- A compact panel showing one row per player, with the character icon and Steam name.
- Tabs: **Damage · Debuffs · Protection · Taken**.
- A scope switch: **This turn / This combat / This run**.
- Each row has a bar showing that player's share of the total, like WoW damage meters.
- A hotkey shows and hides the panel (default: `F7`, to avoid `Tab` which the game may use).
- The panel can be dragged. Its position and visibility are remembered between sessions.
- Hovering a row shows the detail, e.g. damage by source.

## 2. End-of-combat summary
- Shown automatically when the rewards screen appears. It can be closed and turned off in settings.
- Shows every stat for that combat, per player, plus "MVP" highlights (top damage, top
  protector, top debuffer).

## 3. End-of-run summary
- Shown on the game's end-of-run screen (victory or defeat).
- Shows totals per player, records (biggest hit, best combat), and a per-act breakdown.
- **Export:** saved as a JSON file in the mod folder so runs can be compared later.

## 4. Settings
Hotkey, auto-show summaries on/off, overlay opacity and size, language.

## 5. Look & language
- Visual style close to the game's own UI, so it doesn't look out of place.
- Languages: **English** first, plus **French**. More languages can be added later.
